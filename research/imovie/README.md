# iMovie research (2026-11-09)

Reverse engineering of iMovie 10.4.5 for Mac (plus the iPhone edition's Magic Movie and Storyboards) to bring Shorts Editor to iMovie's standard and beyond.

| File | What's in it |
|---|---|
| `imovie-reverse-engineering.md` | **Start here.** The 20 % that does 80 % of the work, the 20 rules iMovie follows everywhere, the ranked 30 % that covers 90 % with what Shorts Editor has, where iMovie fails for Shorts, and the recommended build stages A–F. |
| `imovie-reference.md` | Lookup tables: window anatomy, every menu item and shortcut, each adjustments-bar tool with its defaults, numbers worth copying, catalogues (filters, transitions, titles, themes, sound and voice effects), colour language, iPhone extras. |
| `imovie-docs-notes.md` | Chapter-by-chapter notes from Apple's iMovie User Guide for Mac (83 of 87 pages). |
| `imovie-menus-raw.txt` | The live menu bar as read through Accessibility (modifier codes explained in the reference). |
| `imovie-commandset-raw.txt` | iMovie's default key set with command names and descriptions (shared with Final Cut Pro). |
| `screens/` | 18 screenshots from the hands-on session (test footage only). |
